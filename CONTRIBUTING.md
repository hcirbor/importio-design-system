# Contributing

Thanks for helping improve the Import.io Design System.

1. Create a focused branch from `main`.
2. Add or update component stories and tests with the implementation.
3. Run `npm run check` and `npm run build:storybook`.
4. Open a pull request describing behavior, accessibility, and any visual changes.

Keep components product-agnostic. Application routes, business workflows, and screen layouts belong in consuming applications.
